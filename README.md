# Autoconnect Car Hire

Autoconnect Car hire project is all about creating a super helpful system. Imagine a tool that takes care of all the important stuff for car rental businesses, like handling bookings, keeping track of cars, and making sure everything runs smoothly. That's exactly what the project is about. With Autoconnect, we're aiming to make life simpler for both car rental companies and their customers. Everything will be organized and hassle-free, making life easier for both rental companies and their customers.

This project is built with HTMl5, CSS3 and Vanilla Javascript.
After learning frontend web development(HTML,CSS,Javascript),I decided to build this project to test my skills and practise on web design.

Currently the website is a static website.I intend to extend the capabilities of the project by learning about backend i.e PHP, Postgres among other required backend tools.

The customer can view available cars,book a car(s),pay for the booking fee,create account,login.
Admin can add new vehicles to inventory,see all registered customers,view vehicle maintenance,remove users,update vehicles details,view reports on hiring activities and system performance,register staffs and drivers.
Vehicles - Available,maintenance,hired,booked.
