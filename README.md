# Car Hire Project

Car Hire is a website built for customers who wants to hire car(s) with least effort of going to physical yard.The customer can view available cars,book a car(s),pay for the booking fee,create account,login.

This project is built with HTMl5, CSS3 and Vanilla Javascript.
After learning frontend web development(HTML,CSS,Javascript),I decided to build this project to test my skills and practise on web design.

Currently the website is a static website.I intend to extend the capabilities of the project by learning about backend i.e PHP, Postgres among other required backend tools.
